我们保存什么

游客的本地棋局、设置和聊天演示保存在设备上。正式账号为了登录、好友、私聊、排行榜和跨设备同步，会保存账号资料、好友关系、消息和对局结果。

联机时发生什么

对局会优先尝试 WebRTC 直连；如果需要 TURN 或 WebSocket 中继，棋步和联机信令会经过服务端。私聊不是端到端加密，只有会话双方可以通过认证接口读取。

匿名质量统计

如果开启，系统只采样启动区间、画质档位、入口、链路类型、RTT 区间和重连结果，不上传账号、昵称、好友关系、房号、聊天、棋盘或持久设备标识。可以在设置中关闭。

我们不会做什么

不会把私有 GitHub 仓库、长期令牌或下载凭据放进网页或 APK，也不会为了省事强制清除 WebView 缓存或读取设备上的无关文件。
