我们保存什么

游客的本地棋局、设置和聊天演示保存在设备上。正式账号为了登录、好友、私聊、排行榜、金币签到、钻石余额和跨设备同步，会保存账号资料、好友关系、亲密度、消息、经济记录和对局结果；如果使用正式账号的布局偏好接口，还会保存八个底部按钮的顺序。

经济记录包括金币余额、连续签到和领取日期，以及钻石余额、订单和账本状态。当前钻石支付通道关闭，不会产生真实扣款；这些字段用于保持活动状态和未来合规支付接入的账务边界。

联机时发生什么

对局会优先尝试 WebRTC 直连；如果需要 TURN 或 WebSocket 中继，棋步和联机信令会经过服务端。私聊不是端到端加密，只有会话双方可以通过认证接口读取。

匿名质量统计

如果开启，系统只采样启动区间、画质档位、入口、链路类型、RTT 区间和重连结果，不上传账号、昵称、好友关系、房号、聊天、棋盘或持久设备标识。可以在设置中关闭。

我们不会做什么

当前钻石充值通道关闭，不收集银行卡或支付凭据，也不会把私有 GitHub 仓库、长期令牌或下载凭据放进网页或 APK；不会为了省事强制清除 WebView 缓存或读取设备上的无关文件。
